Cloud sync (Firebase)

Flashcards v0.2 uses the same Firebase project as your Workout webpage automatically. No JSON configuration is needed. Sign in with Google at the top (if not already signed in) using the same account on your laptop and phone. Your cards are stored in a separate Firestore collection, not inside your workout records.

Before first sync: Export a JSON backup of the cards you have already entered. Check that the status says ☁ Synced. If you see a permissions error, Firestore rules may need an additional match for users/{userId}/flashcards/{cardId}; do not replace your existing Workout rules.

Firestore permission example — add to existing rules, do not replace them
match /users/{userId}/flashcards/{cardId} {
  allow read, write: if request.auth != null && request.auth.uid == userId;
}

This match belongs inside the existing service cloud.firestore { match /databases/{database}/documents { ... } } block. Keep all current Workout rules.

Backup / restore

Export a JSON backup anytime. Import combines cards and decks with matching IDs; existing IDs in the backup replace local versions. Back up before switching cloud accounts or removing local data.

Cards saved locally unless cloud sync is enabled. Designed for phone and laptop.
