Project progression
Projects that make you a stronger programmer
1 · Read & explain
Take a 50–100-line Python function. Annotate its inputs, outputs, side effects, error paths, and dependencies.
2 · Break & repair
Create three edge cases, write pytest tests, then fix each failure with a small patch.
3 · Refactor safely
Split a route handler or automation into testable pure functions, preserving behavior with regression tests.
Project A: Flask route detective
Follow a request from route decorator → validation → database/service call → response. Find one failure mode and make the error response predictable.
Project B: OCR/automation hardening
Write a parser that safely handles empty strings, near-misses, wrong types, and partial text. Add parameterized tests for every tricky input.
Project C: Your own code-review assistant
Build an AST-based command-line tool to list functions, imports, exception handlers, and suspicious mutable defaults without executing the inspected file.
