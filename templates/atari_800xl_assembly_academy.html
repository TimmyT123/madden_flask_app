Your Windows development toolkit
You don't need an original Atari 800XL to start. Use the free Altirra emulator and MADS assembler on your Windows computer.
  1. Download Altirra from the author's website. Choose an 800XL model with 64 KB RAM and an XL-compatible kernel; Altirra's built-in OS is fine for initial tests.
  2. Get MADS, a modern Atari assembler. Extract it to a convenient folder and open a terminal in your source folder.
  3. Write a .asm file in VS Code or any plain-text editor; build it with mads color.asm -o:color.xex (if MADS is on your PATH). If not, use the full path to mads.exe.
  4. In Altirra, disable BASIC for the examples, then use File → Boot Image or load the generated executable XEX using Altirra's file-loading interface. Consult the emulator's menus if your version differs.
  5. Run, observe, then change one number. Use the built-in debugger to inspect CPU instructions and hardware registers.
The provided examples assume a standard 40-column text screen and OS services enabled. They are designed as short learning experiments, not production-quality game engines. Use a fresh emulator session between experiments if needed.
