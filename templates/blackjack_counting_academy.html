Counting is a memory and arithmetic skill, not a guarantee of winning. House rules, bet spreads, mistakes, and variance matter.

Your learning path

Follow these steps in order. Practice for about 15–25 minutes at a time, and repeat drills until they feel automatic.

  1. Learn the game and its rules. Understand dealer actions, card values, and why rule variations matter.
  2. Master basic strategy. Learn the correct hit, stand, double, and split decisions for a specified rule set.
  3. Learn Hi-Lo values. Tag each exposed card as +1, 0, or −1.
  4. Count an entire shuffled deck. Reach a running count of zero at the end, accurately.
  5. Convert to true count. Divide the running count by estimated decks remaining.
  6. Practice in short, realistic rounds. Count visible cards while choosing basic-strategy plays.
  7. Study advantage and risk. Understand why counting alone doesn't promise profit.

True-count conversion

In a multi-deck shoe, a running count of +6 means something different when six decks remain versus one deck remaining.

True count ≈ running count ÷ decks remaining
Example: running +6 with 3 decks left → true count +2. The drills below use exact arithmetic; real shoe estimation is approximate.
